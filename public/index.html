Open the access link

This relay only accepts browsers that arrived through the link it printed when it started.

Look in the terminal where you ran npx su-ssh for a line like http://127.0.0.1:3000/#k=… and open that exact URL. Every restart prints a new one, so a link from an earlier run no longer works.

Authentication

Or drop a key file here — it is read in the browser and never written to disk.

The path is resolved by the relay process, not by your browser.

Uses the ssh-agent already running where the relay lives, via SSH_AUTH_SOCK. No credential is typed, sent, or stored. If your key is in ssh-add -l, this will work.
